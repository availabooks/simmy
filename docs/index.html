An Excel simulator you can drop into any page

simmy draws a macOS, Windows or web Excel with a working formula engine and the Excel Educator task pane, which checks the student's work. One YAML module describes the workbook, the tasks, the rubric and an optional narrated demo. One <simmy-app> tag puts it on a page.

Quick start

Pick the way that fits your page. All three render the same simulator.

Script tag

One self-contained file, with Preact, the styles and the YAML parser inside. Point src at a module. 

<script type="module" src="https://cdn.jsdelivr.net/npm/@availabooks/simmy@0.2.3/dist/simmy.js"></script>

<simmy-app src="https://simmy-modules.cotc.workers.dev/references-and-calculations/config.yaml"></simmy-app>

npm

Shares Preact with your app, and loads the YAML parser only when a module needs it. Importing the package registers <simmy-app>. 

npm install @availabooks/simmy
import "@availabooks/simmy";

iframe

For hosts that can't run scripts, such as an LMS page or a CMS block. The package ships dist/embed.html next to dist/simmy.js. Serve both files from your own site. CDNs such as jsDelivr send HTML as plain text, so the iframe can't load from there. 

<iframe src="https://your-site.example/simmy/embed.html?module=https://simmy-modules.cotc.workers.dev/references-and-calculations/config.yaml"
        style="width:100%;height:820px;border:0" title="Excel simulator"></iframe>

The embed page reads module, platform, mode, ribbon and autoplay from its query string. When a student submits, it posts { type: "simmy:graded", report } to the parent page.

The element

<simmy-app> renders into a shadow root. Your page's CSS can't reach in and the simulator's can't leak out, so it looks the same on any site.

Attribute Values What it does
src URL A YAML (or JSON) module to load.
platform auto · mac · win · web The desktop to draw. auto (the default) matches the visitor's computer, macOS or Windows. web is Excel on its own, filling the frame like a browser tab, with no OS around it.
mode movie · kiosk How the narrated demo starts and ends. See Movie and kiosk.
ribbon open · collapsed Start with the full ribbon (the default) or with only its tabs. Students can switch either way.
autoplay false Start with the student in control, with no Play screen.
fit-screen present or absent Fit the whole simulator, heading and playback bar included, to the viewport. It never gets shorter than --simmy-min-height (600px); on a shorter screen the page scrolls.
chrome-offset length or selector With fit-screen, the space a sticky header takes: a length (72px) or a selector to measure (.site-header).
history present or absent On phones, push a history entry so Back closes the full-screen view.
fonts none Skip loading Carlito and Inter from Google Fonts.

A module without a URL

Put the YAML inside the element:

<simmy-app>
  <script type="text/yaml">
    workbook: { name: Totals }
    …
  </script>
</simmy-app>

or set an already-parsed object from script:

document.querySelector("simmy-app").module = { workbook: { name: "Totals" }, … };

Your own heading

A child with slot="head" shows above the desktop. It stays in your page's DOM, so your styles and search engines see it. 

<simmy-app src="…">
  <h2 slot="head">Try it: absolute references</h2>
</simmy-app>

Movie and kiosk

movie default

Nothing plays until the visitor asks. The desktop opens darkened behind a Play button and a Try it yourself button. The demo plays once, with sound, and stops on the finished sheet with the visitor in control. Play starts it over.

The desktop switcher and Start over sit behind the gear on the playback bar, so the page around the movie stays clear.

kiosk

The demo starts by itself, muted, and loops. Visitors can unmute from the playback bar. People who ask their system for reduced motion start in control instead.

The desktop switcher and Start over sit above the desktop.

What students see

The playback bar
Restart, previous and next sentence, play and pause, take control, a time bar to drag, mute, and playback speed. Dragging the time bar moves the cursor and the sheet with it.
Taking control
Clicking the sheet or the task pane pauses the narration where it is and hands over the mouse. Resume continues from that moment.
Excel
Cells, the formula bar, the Name Box, copy and paste, the fill handle, AutoSum, Fill, Clear, Undo and Redo. Ribbon controls the simulator doesn't run are dimmed, and their tooltips say so.
The ribbon
Collapse it with the corner button, a double-click on a tab, or Ctrl+F1. A collapsed ribbon shows over the sheet when a tab is clicked.
The task pane
Each task links to its cell. Do it fills in the solution and Undo it takes it back. Submit checks the rubric and shows the points earned.
The sticky note
Shows the module's steps, or the narration's transcript while the demo plays. It closes once the student has control.
Phones
The page shows a still of the finished sheet. Tapping it opens the simulator full screen.

Events

All three bubble from the element. The demo above logs them as they happen.

Event detail
simmy:ready The parsed module.
simmy:graded { tasks, earned, points }, sent when the student submits.
simmy:error The error. The element also lists the problems in place of the simulator. 
document.querySelector("simmy-app").addEventListener("simmy:graded", (event) => {
  const { earned, points } = event.detail;
  console.log(`Scored ${earned} of ${points}`);
});
Grades are a practice signal. simmy grades in the visitor's browser with a local version of the add-in's rubric. Use the score for feedback, not as a grade of record.

Theming and layout

Set these custom properties on the element:

--excel-green, --excel-green-dark, --excel-green-fill The accent colors of the toolbar and buttons around the desktop.
--excel-grid, --excel-ink Borders and text around the desktop.
--font-sans The font around the desktop.
--simmy-min-height With fit-screen, the shortest the desktop gets (default 600px). 
<simmy-app src="…" fit-screen chrome-offset=".site-header"
           style="--excel-green: #0f6cbd; --simmy-min-height: 640px"></simmy-app>

Modules

A module is one YAML file. It describes the workbook, the tasks and their rubric, the sticky note, and an optional narrated demo. The feature tour module in the demo is a complete example. The full shape: 

version: 1
workbook: { name: Workbook title, sheet: Sheet tab name }
assignment: { title: …, text: …, section: Assessment Section 1 }
sheet:
  rows: 40            # default 40
  columns: 20         # default 20
  columnWidth: 64     # px, default 64
  widths: { A: 12, B: 74 }
  start: D6           # the cell selected at the start; default: the first task's hint
  cells: { B2: Discount, C2: 0.3, E14: "=SUM(E6:E12)" }
  styles:             # applied in order; later entries win
    - { range: C2:C3, format: 0.00% }        # General, 0, 0.00, $#,##0.00, 0.00%, accounting
    - { range: B5:E5 D14:D16, fill: "#800000", color: "#ffffff", bold: true }
    - { range: D6:E12, fill: "#f0e68c", lined: true, align: center, italic: false }
  outlines:
    - { range: D6:E12, weight: 1, color: "#a6a6a6" }
tasks:
  - id: A             # default A, B, C…
    name: Discount    # default: the id
    text: Calculate the "Discount" in cell D6.
    details: [ … ]
    hint: D6          # default: the range's top-left cell
    range: D6:D12     # where Do it writes
    solution: =C6*$C$2
    points: 25        # default: the rules' points added up
    rules:
      - { kind: value, cell: D6, formula: =C6*$C$2, points: 5, message: … }
      - { kind: reference, cell: D6, ref: C2, forms: [C$2, $C$2], points: 5, message: … }
      - { kind: copied, range: D6:D12, points: 5, message: … }
note: { title: Try it, steps: [ … ] }
autopilot:            # optional; default: type each solution and fill its range
  - { audio: 1.mp3, transcript: Peter's Pool Palace is having a sale. }
  - { task: A, type: =C6*C$2, at: D6, done: false, audio: 2.mp3, transcript: Type the discount in D6. }
  - { task: A, at: D6, fill: D6:D12, audio: 3.mp3, transcript: Fill it down through D12. }
  - { submit: true, audio: 4.mp3, transcript: Press Next, then Submit Now. }
poster: { range: B5:E9 }   # the still phones see; default: the top-left of the content
copy:                 # optional wording overrides
  paneTitle: Excel Educator
  unsupported: { video: { title: …, text: … }, book: { title: …, text: … } }
  submitSteps: [Validate Key, Prepare Rubric, Check for Completeness, Evaluate Tasks, Finalize Score]

Checking a module

parseModule() checks a module and reports every problem with its path. The element shows the same list when a module doesn't parse. 

import { parseModule, ModuleError } from "@availabooks/simmy";

try {
  parseModule(data);
} catch (error) {
  if (error instanceof ModuleError) console.error(error.message);
  // tasks[1].rules[0].cell: "D66" is outside the sheet (20 columns, 40 rows)
}

Tasks and grading

Each task has a range where Do it writes the solution, and a list of rules. A rule earns its points when it passes. A task is worth the sum of its rules' points unless points says otherwise.

Rule Passes when
value The cell equals what formula gives on the student's own sheet.
reference The cell's formula refers to ref. With forms, only those $ spellings count, so [C$2, $C$2] requires an absolute row.
copied Every cell in range holds the first cell's formula, copied down or across.

A rule's message is what the student reads when it fails.

Narrated demos

autopilot is the script the demo follows. Leave it out and the demo types each task's solution and fills its range. Each entry can:

  • type a formula at a cell, then fill a range from it.
  • Use the wand on a task. Add done: false to leave the task unfinished.
  • submit: true presses Next, then Submit Now.
  • Carry its own audio clip and transcript. The clip plays at its own speed and the cursor fits the entry into it. An entry with only those two fields waits on the line.

Leave audio and transcript off and the demo keeps its own pace.

Where clips are found

A relative name such as 1.mp3 is a file in the audio folder next to the module. With src, it resolves from the module's URL, so …/pool/config.yaml plays …/pool/audio/1.mp3. A full URL, or a path that starts with /, is used as written. Inline YAML has no folder, so give it full URLs.

Formulas

The engine supports + - * / ^ & %, comparisons, ranges and $ references, and these functions:

ABS AVERAGE CORREL COUNT COUNTA COUNTIF IF MAX MEDIAN MIN MODE MODE.SNGL ROUND SQRT STDEV STDEV.P STDEV.S SUM VAR VAR.P VAR.S

Hosting modules

A module and its clips can live on any static host. When the page is on another origin, the host must send Access-Control-Allow-Origin so the browser lets simmy fetch them.

Our module library is at simmy-modules.cotc.workers.dev, and any page may load from it: 

<simmy-app src="https://simmy-modules.cotc.workers.dev/references-and-calculations/config.yaml"></simmy-app>

The library's module list has every module it serves. To add one:

  1. Put it at hosted-modules/<name>/config.yaml, with its clips in hosted-modules/<name>/audio/. Keep clip names relative.
  2. Run npm run publish-modules. It rewrites the clip names to absolute URLs, writes host-dist/ with this documentation site at its root, and deploys it to Cloudflare Workers.

To publish somewhere else, npm run host-modules -- --base https://… writes host-dist/ for that origin without deploying.

Claude skill

The simmy skill teaches Claude to write modules: the format, the grading rules, and the simmy command that checks them, makes their narration and publishes them. Ask Claude for an assignment and it writes the module, runs simmy validate until it passes, and narrates the demo with simmy narrate.

Download the skill Read it first

Claude Code: unzip it into your skills folder, so the skill is at ~/.claude/skills/simmy/SKILL.md (or .claude/skills/ in a project to share it with the project): 

curl -fsSL https://simmy-modules.cotc.workers.dev/skill/simmy.zip -o simmy-skill.zip
unzip -o simmy-skill.zip -d ~/.claude/skills

Claude apps: upload simmy.zip as a skill in Claude's settings.

The skill runs the command with npx when it isn't installed, so it needs Node 20 or later. To install it: npm i -g @availabooks/simmy.

Develop

npm install
npm run dev     # http://localhost:5173, a page with deliberately hostile styles
npm run docs    # this site, at http://localhost:5173
npm test
npm run check
npm run build   # dist/index.js (npm), dist/simmy.js (standalone), dist/embed.html

To release, bump version in package.json, update the jsDelivr URLs in the README and in docs/index.html, commit, then push a v* tag. The Publish workflow publishes to npm, and jsDelivr serves it a few minutes later.
