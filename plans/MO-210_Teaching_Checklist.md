# MO-210 Excel Associate (Microsoft 365 Apps)

*Teaching Checklist — based on Microsoft’s official Skills Measured outline*

## Exam context

Candidates have 50 minutes to complete the exam. It is performance-based, and task instructions generally do not include the command name, so students need to know where features live, not just what they’re called. Microsoft expects roughly 150 hours of instruction and hands-on experience.

## 1. Manage worksheets and workbooks (25–30%)

### <mark>Import data</mark>

- [ ] Import from text files (.txt/.csv) via Get Data, including choosing delimiters and loading to a sheet
- [ ] Import from online sources (From Web)

### Navigate within workbooks

- [ ] Find/search for data across a workbook (Find & Replace, <mark style="background-color: cyan">“Within: Workbook”</mark>)
- [ ] Navigate to named cells, ranges, or elements (<mark>Name Box, Go To</mark>)
- [ ] Insert and remove hyperlinks (<mark>to web pages</mark>, <mark>places in the document</mark>, email)

### Format worksheets and workbooks

- [ ] Modify page setup (orientation, margins, scaling, size)
- [ ] Adjust row height and column width (exact values and AutoFit)
- [ ] <mark>Customize headers and footers, including built-in elements like page numbers and file name</mark>
- [ ] <mark>Customize options and views; manage the Quick Access Toolbar</mark>
- [ ] <mark>Switch among Normal, Page Layout, and Page Break Preview</mark>
- [ ] Freeze panes (top row, first column, custom)
- [ ] <mark>Change window views (New Window, Arrange, Split)</mark>
- [ ] <mark>Modify built-in workbook properties (Title, Author, Tags, etc.)</mark>
- [ ] <mark>Display formulas (Show Formulas)</mark>

### Prepare for collaboration and distribution

- [ ] Set a print area
- [ ] <mark>Save/export in alternative formats (PDF, CSV, .xls, etc.)</mark>
- [ ] Configure print settings (print titles, scaling, gridlines, selection)
- [ ] <mark>Inspect workbooks (Document Inspector, Accessibility, Compatibility checkers)</mark>
- [ ] Manage comments vs. notes (insert, reply, resolve, delete, show/hide)

## 2. Manage data cells and ranges (25–30%)

### Manipulate data

- [ ] Paste Special options (values, <mark>formats, transpose, operations</mark>)
- [ ] Auto Fill (series, <mark>patterns, fill handle</mark>, Fill Series dialog)
- [ ] Insert/delete multiple rows or columns
- [ ] <mark>Insert/delete cells with shift direction</mark>
- [ ] <mark>Generate numeric data with RANDBETWEEN() and SEQUENCE()</mark>

### Format cells and ranges

- [ ] Merge and unmerge (including Merge & Center <mark>vs. Merge Across)</mark>
- [ ] <mark>Alignment, orientation, and indentation</mark>
- [ ] Format Painter (single and double-click for multiple uses)
- [ ] Wrap text
- [ ] Number formats (currency, accounting, percentage, date, decimals)
- [ ] Format Cells dialog box (borders, fills, <mark style="background-color: cyan">protection tab awareness</mark>)
- [ ] Apply cell styles
- [ ] <mark>Clear formatting only (vs. clearing contents)</mark>
- [ ] <mark>Group worksheets to format several at once, then ungroup</mark>

### Named ranges

- [ ] Define a named range (Name Box, Define Name, Create from Selection)
- [ ] Reference a named range in formulas

### Summarize data visually

- [ ] <mark style="background-color: cyan">Insert Sparklines (line, column, win/loss) and modify markers/style</mark>
- [ ] Apply built-in conditional formatting (highlight rules, top/bottom, data bars, color scales, icon sets)
- [ ] Remove conditional formatting (from selection vs. entire sheet)

## 3. Manage tables and table data (10–15%)

### Create, modify, filter, and sort tables

- [ ] Create a table from a range (with/without headers)
- [ ] Apply table styles
- [ ] <mark>Convert a table back to a range</mark>
- [ ] Add/remove table rows and columns
- [ ] <mark>Configure style options</mark> (banded rows/columns, header row, first/last column)
- [ ] Insert a Total Row and change its function per column
- [ ] Filter records (text, number, date filters, custom criteria)
- [ ] Sort by multiple columns (Sort dialog, multiple levels)

## 4. Perform operations by using formulas and functions (15–20%)

### References

- [ ] Relative, absolute, and mixed references (F4 cycling)
- [ ] Structured references in table formulas

### Calculate and transform

- [ ] SUM, AVERAGE, MIN, MAX
- [ ] COUNT vs. COUNTA vs. <mark>COUNTBLANK</mark> (and when each applies)
- [ ] IF with comparison operators and text/number results
- [ ] <mark>SORT() and UNIQUE()</mark> dynamic arrays (including spill behavior)

### Text functions

- [ ] LEFT, RIGHT, MID
- [ ] UPPER, LOWER, LEN
- [ ] CONCAT and <mark>TEXTJOIN</mark> (delimiters, ignore-empty argument)

## 5. Manage charts (15–20%)

### Create, modify, and format charts

- [ ] Create charts (column, bar, line, pie, and so on) from selected data
- [ ] <mark>Create a chart sheet (Move Chart → New sheet)</mark>
- [ ] Add a data series to an existing chart (Select Data)
- [ ] <mark>Switch rows/columns</mark>
- [ ] Add and modify chart elements (titles, axis titles, legend, data labels)
- [ ] Apply chart layouts (Quick Layout) and chart styles
- [ ] <mark>Add alternative text for accessibility</mark>

## Teaching tips

- The objective domain lists 64 sub-objectives, so it’s realistic to give every one a hands-on task.
- Dynamic array functions (SEQUENCE, SORT, UNIQUE) and TEXTJOIN are where students coming from older Excel versions most often get caught.
- Because exam instructions don’t name commands, phrase practice tasks by outcome (“Make the top row stay visible when scrolling”) rather than by feature name (“Freeze the top row”).
